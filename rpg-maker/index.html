🎬 劇情與互動編輯器

選事件、排對話與選項，再試看玩家會看到的畫面。

地圖素材：一格 32×32 像素。建議畫 32×32 或 64×64 的正方形；上傳後最長邊縮到 128 以內，放到地圖時顯示為 32×32。非正方形圖會在格內變形。

地圖背景圖：建議尺寸＝地圖格數 × 32，例如 40×30 格畫 1280×960；上傳後最長邊縮到 2048 以內，比例保持不變。

🎭 主角設定

上傳人物圖後可在此選為主角，地圖與試玩會使用選定的圖。在「🎬 劇情互動」新增「🗣 主角發言」，會自動帶入主角名稱與對話圖片。

人物圖：一格地圖為 32×32；角色每個畫格顯示寬 32，高度依原比例。建議每格 32×48，3 欄 4 列整張 96×192；也可用每格 64×96、整張 192×384 提高清晰度。上傳時整張最長邊縮到 768 以內。

上傳行走圖或差分圖後，設定欄數、列數，再點選畫格組出走路、眨眼等動作。

角色頭像：建議 96×96 或 192×192。半身立繪：建議 320×480 或 640×960，透明 PNG 最合適。上傳時最長邊縮到 600 以內；實際對話顯示大小與位置可在「🎬 劇情互動」逐句調整。

單檔上限 2MB。上傳後可在地圖設定背景音樂，或在事件指令中播放。

🧩 人物與物件

集中管理所有地圖上的 NPC、可調查物件、存檔點和傳送點。選取項目即可修改外觀、位置、活動與觸發方式；對話和其他指令可開啟劇情編輯器。

新手教學：做出你的第一個遊戲

① 五分鐘快速上手
  1. 到「🗺 地圖」，選地形後在地圖上拖曳畫。地圖不夠大，用「地圖大小」調整。
  2. 選「⭐ 新增事件」，點地圖放上一個 NPC，再到「🎬 劇情互動」編排對話與選項。
  3. 用「🧑 主角起點」決定出發位置，按「▶ 試玩」測試。
  4. 到「🚀 發布」產生遊戲代碼，備份或分享給朋友。
② 上傳素材與圖層
  1. 到「🎨 素材」上傳圖片（建議 32×32 或 64×64 的正方形）。
  2. 回地圖，在「② 我上傳的素材」點選，再在地圖上點或拖曳擺放。
  3. 圖層：素材會放在「④ 圖層」中亮起來的那一層。例如地板放下層、家具放中層。按「＋新增圖層」可以自己加，也能改名、調整上下順序、刪除。
  4. 勾「蓋住角色」的圖層會畫在主角上方（樹冠、屋簷）。「顯示」可暫時隱藏某層，方便編輯。
  5. 橡皮擦只擦目前選中的圖層。素材有透明處卻不想露出綠色，地形請選「無（透明）」。
③ 碰撞（走得過、走不過）

用「🧱 畫碰撞」在地圖上塗抹，紅色格子走不過去。素材也可以在「🎨 素材」勾選「有碰撞」。碰撞跟畫面顏色無關。

④ 人物與動作（差分圖）
  1. 到「🧍 人物」上傳人物圖，把「橫向幾格」「直向幾格」填成和你的圖一樣，圖上會出現格子與畫格編號。
  2. 按「＋新動作」，在「畫格選法」選：
    　• 固定順序：點哪幾格就播哪幾格（例如眨眼點 0、1、0）。
    　• 依方向：先選「下」「左」「右」「上」某一個方向，再點格子（例如往下走點 0、5、10）。
  3. 想讓它在行走時播放，就勾「移動時播放」；站著不動時的畫格可在「站立」欄填編號。點錯了可按「↶ 刪最後一格」。
  4. 非走路動作可選「事件指令手動播放」、「待機時定期播放」或「每次開始對話時播放」。眨眼建議設待機每 3～5 秒；劇情中也可用「🏃 主角動作」指令播放驚訝等動作。
  5. 按「設為主角」後，到「▶ 試玩」確認效果。
⑤ 對話與劇情分支
  1. 先到「🧍 人物」設定主角名稱與對話頭像。頭像或立繪可在同頁下方上傳。
  2. 在「🎬 劇情互動」選地圖與事件，按「🗣 主角發言」加入主角台詞；「💬 對話」可切換為 NPC、主角或旁白。對話可逐句調整立繪大小和位置。
  3. 加入「❓ 讓玩家選擇」可設定跳轉標籤、顯示條件與選後效果；選項後也可以接一條主角發言指令，讓主角回應玩家的選擇。
  4. 上方可預覽玩家畫面，流程檢查會提示找不到的標籤。按「▶ 從這裡試玩」可直接從事件旁測試。
  5. 不知道怎麼開始時，在事件設定按「📋 套用「審問」範例」，照著改最快。
⑥ 圖片尺寸速查（一格 32×32）
  • 地圖素材與旋轉角度圖：32×32 或 64×64；最長邊縮到 128，顯示在 32×32 格內。
  • 人物圖：每格 32×48 或 64×96；3 欄 4 列整張分別為 96×192 或 192×384；整張最長邊縮到 768。
  • 地圖背景圖：格數 × 32；例如 40×30 格為 1280×960；最長邊縮到 2048。
  • 角色頭像：96×96 或 192×192；半身立繪：320×480 或 640×960；最長邊縮到 600。對話指令可調顯示寬度與位置。
  • 未來若加入道具圖示：建議 32×32 或 64×64；敵人圖：建議 128×128 或 256×256；戰鬥特效逐格圖：建議每格 64×64。這三類目前尚未提供圖片上傳。
⑦ 解謎推理怎麼做
  1. 在「📦 資料庫」新增線索。
  2. 調查物件的事件用「🔎 獲得線索」，玩家可在「☰ 選單」的筆記本查看。
  3. 審問 NPC 時用「📜 讓玩家出示證物」，對的跳一條路、錯的跳另一條。
  4. 用變數記錄信任度、真相，再用「若變數符合條件就跳到標籤」決定結局。
⑧ 開始畫面、人物物件與玩家操作
  1. 在「🎞 開始畫面」上傳背景、編輯與新增按鈕，並設定互動及背包快捷鍵。開始畫面背景建議 640×448 或 1280×896。
  2. 在「🧩 人物與物件」集中管理 NPC、調查物件、地點對話、存檔點、出口與蠟燭。NPC 可設定自主走動、隨機話題、預設對話圖片；物件可設定發光或靠近才出現。
  3. 在「🗺 地圖」可設定昏暗視野與上傳玩家導覽圖。導覽圖建議尺寸為地圖格數 × 32。劇情指令可設置放置或手持照明、畫面抖動、暫停、淡入淡出及慢速鏡頭。
  4. 試玩時用空白鍵互動與繼續對話；按 I 開啟背包、詳細資料、線索和對話紀錄，亦可查看地圖和目前位置。
