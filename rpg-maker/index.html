📝 與成熟解謎遊戲相比，還待完善的功能
  • 多個存檔欄位與存檔縮圖：目前同一專案只有一個遊戲存檔。
  • 可重用的共用劇情：目前相似機關常需要複製積木，再各自修改。
  • 依玩家進度給出的同伴提示：目前可做條件對話，但沒有專用的提示階段編輯器。
  • 結局條件總覽：目前能用變數與標籤做多結局，缺少集中檢查各結局是否可達的畫面。
  • 完整遊玩路徑測試：本頁能找缺少的連結，但推椅子、碰撞、遮擋與演出仍需在「▶ 試玩」實際走一遍。

🎬 劇情與互動編輯器

選事件、排對話與選項，再試看玩家會看到的畫面。

地圖一格為 32×32 像素。單格素材建議 32×32 或 64×64；兩格沙發可畫 64×32 或 128×64，三格高的樹可畫 32×96 或 64×192。上傳會等比縮至最長邊 512 以內。到素材設定選預設佔格，放到地圖後仍可單獨調整大小及像素位置。

地圖背景圖：建議尺寸＝地圖格數 × 32，例如 40×30 格畫 1280×960；上傳後最長邊縮到 2048 以內，比例保持不變。

預覽下方的對話框與按鈕。到「劇情互動」可逐句選頭像、立繪或不顯示圖片。

🕯 光源編輯器

一種光源可放在多張地圖上。每格 32×32 像素；光源圖片建議 32×32 或 64×64，上傳後最長邊會縮到 128。半徑以地圖格計算，燃燒時間只在試玩進行時計時；0 秒代表不會燃盡。

👁 照亮範圍預覽

預覽會顯示放置與手持的不同半徑。地圖的昏暗濃度與像素尺寸請到「地圖 → 光影與霧氣」設定。

🎞 動畫編輯器

把定格圖、自繪 CG、鏡頭、震動、轉場、人物登場、霧氣及音效依序排成一段動畫。可重複套用在開場或任一劇情事件；修改動畫後引用它的地方會同步更新。

⓪ 新版編輯器：功能在哪裡？
  1. 上方只有五個大分頁：「📁 專案」「🛠 編輯器」「▶ 試玩」「🚀 發布」「❓ 教學」。所有製作工具都在「🛠 編輯器」裡。
  2. 「🛠 編輯器」左邊是固定的編輯器清單，分成「場景與地圖」「角色與物件」「劇情與解謎」「畫面與聲音」四類。點過的編輯器會留在上方的分頁列，可以像瀏覽器分頁一樣切換或關閉。
  3. 不知道功能在哪：在左上搜尋框輸入想做的事，例如「鑰匙」「蠟燭」「背景」「存檔」，會同時列出編輯器與「⚡ 功能捷徑」；在任何地方按 Ctrl＋K 也能直接搜尋。
  4. 地圖編輯器的右側分成「🖌 繪製與圖層」「👆 選取的物件」「⚙ 地圖設定」「🌙 光影霧氣」四個分頁；在地圖上點一個物件會自動切到「選取的物件」。
  5. 「🧩 人物與物件」上方有「跳到：」列，可直接跳到對話、拿取放置、推動／高處、光源、存檔點等區塊；有綠點的代表已設定。
  6. 想最快做出一個機關：到「🧪 解謎配方」按一下，就會建好鑰匙門、密碼鎖、推椅子調查高處、存檔點、雙向房門、驚嚇點、體力陷阱、拉桿暗門等，彼此都已連好，可直接試玩再改文字。
① 第一次做解謎遊戲：照順序完成一間房
  1. 到「📁 專案」按「＋空白專案」並取名。空白專案不帶村長、史萊姆或寶箱；「＋範例專案」才會帶入教學用的冒險地圖。
  2. 到「🛠 編輯器 → 🗺 地圖編輯器」把「第一張地圖」改名為「展覽室」。先用地形「地板」畫出可走的地方；紅色碰撞格走不過去。把主角起點放在房間入口。
  3. 到「📦 道具與線索」按「＋線索」，建立「破損的畫框」與說明。線索會放在筆記本；要能拿在背包、使用或放回地圖，則應按「＋道具」。
  4. 到「🧩 人物與物件」選「調查物件」按「＋新增」，取名「畫框」，並在地圖上調位置。到「🎬 劇情互動」編輯該物件，先寫旁白，再加「🔎 獲得線索」指令。
  5. 到「▶ 試玩」按「新遊戲」，走到畫框旁面向它按空白鍵。確認對話出現後按 I 打開背包與筆記本。若角色走不到畫框，回地圖檢查碰撞或把主角起點移近。
  6. 到「🚀 發布」先用「產生遊戲代碼」備份。要跨裝置編輯時，再登入並按「儲存雲端草稿」；「發布目前版本」會建立玩家可讀的公開版本，還需部署網頁才能取得可開啟的網址。
② 上傳素材與圖層
  1. 到「🛠 編輯器 → 🎨 素材庫」上傳圖片（單格建議 32×32；大型物件依佔格數 × 32 繪製）；上傳後會另存到共用素材庫。其他專案可在此按「加入此專案」使用，也能載入帳號裡的雲端素材。
  2. 回地圖，在「② 我上傳的素材」點選，再在地圖上點或拖曳擺放。
  3. 圖層：素材會放在「④ 圖層」中亮起來的那一層。例如地板放下層、家具放中層。按「＋新增圖層」可以自己加，也能改名、調整上下順序、刪除。
  4. 勾「蓋住角色」的圖層會畫在主角上方（樹冠、屋簷）。「顯示」可暫時隱藏某層，方便編輯。
  5. 橡皮擦只擦目前選中的圖層。素材有透明處卻不想露出綠色，地形請選「無（透明）」。
③ 碰撞（走得過、走不過）

用「🧱 畫碰撞」在地圖上塗抹，紅色格子走不過去。素材也可以在「🎨 素材庫」勾選「有碰撞」。碰撞跟畫面顏色無關。

④ 人物與動作（差分圖）
  1. 到「🛠 編輯器 → 🧍 人物與動作」上傳人物圖，把「橫向幾格」「直向幾格」填成和你的圖一樣，圖上會出現格子與畫格編號。
  2. 按「＋新動作」，在「畫格選法」選：
    　• 固定順序：點哪幾格就播哪幾格（例如眨眼點 0、1、0）。
    　• 依方向：先選「下」「左」「右」「上」某一個方向，再點格子（例如往下走點 0、5、10）。
  3. 想讓它在行走時播放，就勾「移動時播放」；停下後會保留最後方向，可在四方向停格欄各自指定畫格。點錯了可按「↶ 刪最後一格」。
  4. 非走路動作可選「事件指令手動播放」、「待機時定期播放」或「每次開始對話時播放」。眨眼建議設待機每 3～5 秒；劇情中也可用「🏃 主角動作」指令播放驚訝等動作。
  5. 按「設為主角」後，到「▶ 試玩」確認效果。
⑤ 對話與劇情分支
  1. 到「🛠 編輯器 → 🎬 劇情互動」，左邊選事件。最上面的「🔗 這個事件的前因後果」會用白話寫出：①什麼時候開始（按空白鍵、踩到、進地圖）②需要先發生什麼（哪個事件給的線索／開關）③做完會影響誰。出現「⚠ 沒有任何事件會給」就代表玩家會卡住。
  2. 「📜 劇情步驟」的編號就是播放順序。用「💬 對話」「🗣 主角說」加台詞，對話框圖片與位置收在每句的「🖼 頭像、立繪與位置（選填）」裡。
  3. 讓玩家選擇：加入「❓ 讓玩家選擇（分支）」，下面會出現 A、B…不同顏色的欄，每一欄就是「選了這個之後」的劇情，直接在欄裡按「💬 對話」「📝 給線索」等按鈕加步驟。所有欄走完都會回到下一個編號，不需要設定標籤。
  4. 看狀態走不同路：加入「🔀 條件分支」，選「玩家已有某條線索／背包有某個道具／某個開關打開／某個物件是某個差分樣子」，綠色「✔ 符合時」和紅色「✘ 不符合時」各放要發生的事。分支裡還可以再放分支。
  5. 按「▶ 文字預演」會從第 1 步跑到最後，遇到選項或條件由你替玩家選，不用進遊戲就能檢查每條路線。按「🔗 連動關係圖」可以看整個遊戲：最左邊是一開始能做的事，箭頭表示做完左邊、右邊才能進行。
  6. 步驟可以拖曳換順序，也能拖進分支欄。舊專案的「選後立刻說的話」會自動變成分支欄裡的一句台詞；舊式的標籤、跳過幾條等積木收在「🧰 進階」裡，仍然可以用。
⑥ 圖片尺寸速查（一格 32×32）
  • 可繪製地形（地板、牆面）：畫正方形 32×32 或 64×64，上傳後每格顯示 32×32。
  • 獨立地圖物件：一格 32×32；兩格沙發可畫 64×32 或 128×64，三格高的樹可畫 32×96 或 64×192。上傳最長邊縮到 512；放置時可調佔格、像素位移。
  • 人物圖：每格 32×48 或 64×96；3 欄 4 列整張分別為 96×192 或 192×384；整張最長邊縮到 768。
  • 地圖背景圖：格數 × 32；例如 40×30 格為 1280×960；最長邊縮到 2048。
  • 角色頭像：96×96 或 192×192；半身立繪：320×480 或 640×960；最長邊縮到 600。對話指令可調顯示寬度與位置。
  • 道具背包小圖：建議 32×32 或 64×64；文件檢閱大圖：建議 320×448 或 640×896，均可在「道具與線索」上傳。敵人目前使用符號；戰鬥特效逐格圖尚無專用上傳欄位。
⑦ 解謎推理怎麼做
  1. 第一次做解謎時，到「🛠 編輯器 → 🧭 解謎檢查」按「在目前地圖加入範例」。它會建立畫作、線索和門；先試玩，再拆開積木改成自己的故事。
  2. 在「📦 道具與線索」新增線索。調查物件的事件用「🔎 獲得線索」，玩家可在「☰ 選單」的筆記本查看。
  3. 審問 NPC 時用「📜 讓玩家出示證物」，對的跳一條路、錯的跳另一條。用變數記錄信任度、真相，再用「若變數符合條件就跳到標籤」決定結局。
  4. 每做完一個房間，到「🧭 解謎檢查」查看缺失的線索、錯誤的跳轉、消失的素材與傳送位置；再從開始畫面完整試玩。檢查器只能找設定問題，不能替代實際遊玩。
⑧ 開始畫面、人物物件與玩家操作
  1. 在「🎞 開始畫面」上傳背景、編輯與新增按鈕，並設定互動、背包、地圖、讀取存檔、離開及移動快捷鍵。到「📦 道具與線索」可為個別道具設定使用鍵；「🎛 玩家介面」可設計資料頁的排版、透明度、顯示內容及按鈕。開始畫面背景建議 640×448 或 1280×896。
  2. 在「🧩 人物與物件」集中管理 NPC、調查物件、地點對話、存檔點、出口與蠟燭。NPC 可設定自主走動、隨機話題、預設對話圖片；物件可設定發光或靠近才出現。
  3. 在「🗺 地圖編輯器」可設定像素化昏暗、漸暗、霧氣與燈光閃爍；勾選即時預覽後點地圖可移動預覽位置。也可上傳玩家導覽圖。導覽圖建議尺寸為地圖格數 × 32。劇情指令可設置放置或手持照明、畫面抖動、暫停、淡入淡出及慢速鏡頭。
  4. 試玩時用空白鍵互動與繼續對話；按 I 開啟背包、詳細資料、線索和對話紀錄，亦可查看地圖和目前位置。按 Z 可切換放大觀察，按鍵與倍率可在開始畫面的「快捷鍵」修改。
⑨ 推椅子調查高處：一步一步設定
  1. 先在地圖擺放椅子與線索板。線索板需要有地圖事件；要播放的對話與指令，放進線索板事件的「劇情互動」。
  2. 到「🛠 編輯器 → 🧩 人物與物件」選椅子，展開「🪑 推動機關與高處調查」。在「快速設定」選線索板事件。
  3. 填椅子最後要停的位置。看的是椅子圖片左上角地圖格，X 往右、Y 往下，最左上是 (0,0)。例如椅子最後占用第 6～8 欄、第 8～11 列，就填 X=6、Y=8；不要填線索板格或主角格。
  4. 按「套用椅子線索板機關」。下方「椅子推到指定位置後才可站上」會自動勾選，並顯示剛才的 X、Y。上方是準備套用的位置，下方是目前已生效的位置；改上方數字後要再按一次套用。也可直接改下方已生效的位置。
  5. 若要主角站上椅子當下自動播放劇情，在「站上後自動執行的事件劇情」選線索板事件；若希望玩家自己調查，保留「不自動執行」，站上後面向線索板按空白鍵。線索板的「調查前需要站在哪個物件上」會由快速設定連到椅子。
  6. 「推動後觸發事件」的座標只用來設定椅子抵達時的提示／開關／額外劇情。它和可站上位置可以相同，也可以不同。試玩時先與椅子互動，再推到目的地；靠近椅子按方向鍵或空白鍵站上。
⑩ 高處多格調查、拿取放回與地板機關
  1. 書櫃保持不可站上、不可拿取；椅子勾可站上。書櫃若同時有低處與高處物品，在「同一櫃子的多個展示位置」各新增一個位置；只有高處位置需要站上椅子，低處保持地面可操作。編輯器內的高處位置示意以綠色標椅子、橘色標目標、藍色標書櫃、黃色標調查格。
  2. 在書櫃「分格互動」點蠟燭或小熊格，分別寫對話；多格要共用同一段分支時按「多格共用」，再點其他格。滑鼠移到地圖畫布或分格按鈕，可看地圖 X、Y 和物件內格數。主角站上椅子後面向書櫃按空白鍵，可從可觸及的調查格選單中選位置。
  3. 熊玩偶：先到「📦 道具與線索」建立熊玩偶道具；回「🗺 地圖編輯器」選取熊玩偶，按「🎒 設定拿取與放回」，在「拿起時取得的道具」選剛建立的道具。拿取後圖片消失、背包增加。回到書櫃的操作格按空白鍵，選目前持有的小熊或其他允許物品；有多個展示位置時，放置選單會依各位置分開顯示。桌子事件的「物件拿取與放回」可勾選小熊、蠟燭等多種可放道具，並分別按「在地圖點圖片位置」和「在地圖點站立位置」選好兩格。試玩時只顯示目前持有的選項；桌面一次只放一件，拿起後才能改放另一件。
  4. 裂縫：新增「地板裂縫／機關」事件，在「地板格互動」選走過音效、調查文字與道具。調查後可換成洞的地板圖片，並設定禁止通行與阻擋對話。事件進度會隨遊戲存檔保存。
⑪ 椅子、蠟燭與書櫃：檢查高處解謎
  1. 選椅子，在「推動機關與高處調查」勾「可站上」，填椅子最後停留的格子。推到那格的規則只寫提示文字；若希望站上後才調查蠟燭，不要在推動規則選蠟燭事件。
  2. 只在高處蠟燭的「調查前需要站在哪個物件上」選椅子；書櫃本身不限制站立，並在「同一櫃子的多個展示位置」只讓高處位置要求椅子。蠟燭不要勾可推動或可站上；書櫃「拿起時取得的道具」選「不可拿起」。
  3. 試玩時先推椅子到定位，再從椅子下方靠近站上；面向蠟燭或書櫃按空白鍵。如果只出現推動提示，回椅子檢查「推動後觸發事件」是否誤選高處事件。
⑫ 圖片差分、床上姿勢與家具存檔
  1. 差分（同一個物件的不同樣子）：到「🧩 人物與物件」選蠟燭，按上方「跳到：🎭 差分」，再按「🕯 蠟燭：熄滅／點燃」。會出現兩個樣子：「熄滅」和「點燃」。在每個樣子的「這個樣子的圖片」選或上傳圖片（例如熄滅的蠟燭、點燃的蠟燭）。試玩時對著蠟燭按空白鍵：熄滅時看到「點亮」，點燃時看到「熄滅」，選了就立刻換圖，點燃的樣子同時會發光。
  2. 杯子、花瓶、畫作也一樣：按「🥛 杯子：裝滿水→喝完」，選項「喝掉」會換成空杯的圖，並在「✨ 變成這個樣子時發生的事」給玩家線索（例如杯底的刻字）；之後在空杯的樣子選「仔細看看」可再讀一次。也可以設定「需要道具才能這樣做」，例如要有火柴才能點亮。
  3. 想讓別的事件改變這個物件（例如拉下拉桿後畫作變樣）：在那個事件的「🎬 劇情互動」加入「🎭 切換物件差分」積木，選物件和要變成的樣子。懶得自己設定時，到「🧪 解謎配方」按「🥛 差分：喝完的杯子露出線索」或「🕯 可點亮／熄滅的蠟燭」，會連示意圖一起建好。
  4. 放在書櫃「多個展示位置」的蠟燭，點亮／熄滅選項由書櫃位置自動提供，圖片一樣跟著差分切換。
  5. 選床的劇情，加「🛏 主角躺下／調整站位」。選睡覺動作、面向、相對床的格數與像素微調，右側示意圖會顯示疊放位置。角度可輸入 90 或 -90；「人物蓋在物件前」可避免整個角色被床遮住。起身時再加一條同指令，選「恢復正常站姿」。
  6. 在床或其他家具的「人物與物件」設定，勾「可當存檔點」。試玩調查家具時會先播放共用主劇情，劇情播完才顯示可自行修改的「是否存檔」詢問。
⑬ 踩格轉場與跟隨物件的互動格
  1. 在「人物與物件」新增「前往下一張地圖」或「踩到指定位置對話」，按「在地圖點選觸發格」標記玩家要走進的地板格；觸發方式保持「踩到時」、玩家可穿越保持勾選。
  2. 在出口的「劇情互動」打開「🌀 傳送」，選目的地地圖，再按「在目的地地圖點選主角落點」。選可行走的空格，返回後 X、Y 會自動填好；可先加對話或開門音效，再執行傳送。
  3. 物件的「拿取與放回」有兩個不同位置：放下後圖片出現的位置，以及主角站著操作的位置。用旁邊按鈕在地圖點選，之後移動或推動該物件，這兩個位置會一起移動。試玩前到「解謎檢查」找無法到達或未連結的設定。
⑭ 參考房間：書櫃高低兩處、椅子、存檔與電燈
  1. 到「🚀 發布 → 我的專案」載入雲端草稿「高處互動示範房間」。這是獨立範例，不會覆蓋「房間」或「房間2」。先按「▶ 試玩」，再回「🧩 人物與物件」看每件物品的設定。
  2. 書櫃選「同一櫃子的多個展示位置」：低處的圖片格是 (3,3)，主角操作格是 (3,5)；高處的圖片格是 (2,2)，主角站在椅子上時所在格是 (2,5)。兩個位置都允許放小熊或蠟燭，但各位置一次只能放一件。
  3. 先在書櫃低處拿起熊。椅子初始在 (8,7)，先互動，再推到 (2,5)；推到後從下方走上椅子。站上後人物地圖座標仍是椅子占的 (2,5)，只有畫面位置往上抬，沒有把 Y 自動減一。因此高處「主角站的位置」填 (2,5)，不是蠟燭的 (2,2)。
  4. 站上椅子後操作高處位置，可點亮／熄滅蠟燭並自動換圖，也可拿走蠟燭。拿起兩件後，到低處可選放蠟燭，到高處可選放熊；選單只列出背包裡有、這個位置允許的物品。
  5. 床在下方；「對話與互動」的提示問要不要躺，選「躺一下」才執行角度 90° 的睡覺積木，選「暫時不要」會離開。紀錄本先說共用台詞，才問是否存檔。右上方的電燈開關會切換整間房的昏暗效果。
⑮ 範例房間設定快速入口

先到「🚀 發布 → 我的專案」載入「高處互動示範房間」，再按下方按鈕。按鈕會打開對應的物件與設定區塊。

書櫃：低處／高處位置查看兩個展示格、操作格和可放道具。
小熊：拿取後進背包查看「拿起時取得的道具」。
蠟燭：高處限制與換圖拿取在「單件物品拿取」，點亮圖片在「點亮／熄滅與換圖」；書櫃的多個展示位置會自動給點亮／熄滅選項。
椅子：先互動、推動、站上目標位置與推動提示都在「推動機關與高處調查」。
床：躺／不躺與姿勢選項在「對話與互動」；躺下角度在下方四條劇情指令。
紀錄本：對話後詢問存檔第一句在「對話與互動」，詢問文字在「存檔點」。
電燈：切換整間房昏暗此物件連到「房間電燈」光源。

登入後可儲存草稿與素材。草稿只供你的帳號編輯；發布會建立供任何人遊玩的公開版本。

尚未登入

🚀 發布遊戲

尚未發布

  1. 在上方登入，按「儲存雲端草稿」。
  2. 按「發布目前版本」（之後改了遊戲，要再按一次才會更新給玩家）。
  3. 按下方「複製遊玩連結」傳給大家。打開連結只會看到遊戲畫面（開始畫面 → 遊戲），看不到編輯器；手機會自動出現方向鍵。

從電腦的 file:// 檔案開啟時，才需要填下面的網站網址；用網站上的編輯器（github.io）就不用填。

部署後填入首頁網址，再複製下方遊玩連結。若直接從已部署的網站開啟編輯器，可留空。網址後會自動加上 ?game=專案ID。
