📁 我的遊戲專案

每個故事有自己的地圖、人物、素材、劇情與設定。切換時會先自動儲存目前專案。

昏暗減速只在沒有手持燈、也不在已點亮的燈旁時生效。

🖼 背景圖位置與尺寸

先選背景圖，再調整等比鋪滿或完整顯示、縮放及位移。地圖編輯區會即時預覽；背景只改外觀，走路碰撞仍由地形和物件設定。

可先選「等比鋪滿」，再微調位置。

🌙 光影與霧氣

調整後會立刻更新地圖預覽與試玩畫面。像素越大，光影邊緣越像復古像素遊戲。

🗺 玩家地圖

地圖可沿用你拼出的地形，也可另上傳一張導覽圖。導覽圖建議尺寸＝地圖格數 × 32；例如 40×30 格為 1280×960，上傳後最長邊縮到 2048 以內。

🎨 創作工作室

人物、素材、地圖上的人物與物件、劇情和風格共用同一份專案資料。選一區編輯，其他區會同步更新。

🎬 劇情與互動編輯器

選事件、排對話與選項，再試看玩家會看到的畫面。

地圖一格為 32×32 像素。單格素材建議 32×32 或 64×64；兩格沙發可畫 64×32 或 128×64，三格高的樹可畫 32×96 或 64×192。上傳會等比縮至最長邊 512 以內。到素材設定選預設佔格，放到地圖後仍可單獨調整大小及像素位置。

地圖背景圖：建議尺寸＝地圖格數 × 32，例如 40×30 格畫 1280×960；上傳後最長邊縮到 2048 以內，比例保持不變。

♻ 共用素材庫

上傳過的圖片、人物動作、音效與字體會保存在此裝置的共用素材庫。切換到其他遊戲專案後，按「加入此專案」即可重用；從目前專案刪除素材，不會刪除共用庫版本。

☁ 雲端素材

登入後可從已儲存的雲端專案帶入素材，在不同裝置也能使用。先在「🚀 發布」儲存雲端草稿。

🎭 主角設定

100%＝寬 32 像素；放大只改外觀，走路和碰撞仍佔一格。地圖預覽與試玩即時更新。

上傳人物圖後可在此選為主角，地圖與試玩會使用選定的圖。在「🎬 劇情互動」新增「🗣 主角發言」，會自動帶入主角名稱與對話圖片。

人物圖：一格地圖為 32×32；角色每個畫格顯示寬 32，高度依原比例。建議每格 32×48，3 欄 4 列整張 96×192；也可用每格 64×96、整張 192×384 提高清晰度。上傳時整張最長邊縮到 768 以內。

上傳行走圖或差分圖後，設定欄數、列數，再點選畫格組出走路、眨眼等動作。

角色頭像：建議 96×96 或 192×192。半身立繪：建議 320×480 或 640×960，透明 PNG 最合適。上傳時最長邊縮到 600 以內；實際對話顯示大小與位置可在「🎬 劇情互動」逐句調整。

🎵 BGM 與音效編輯器

內建音樂與音效由瀏覽器即時合成，可直接用於你的遊戲。可設定開始畫面、每張地圖與戰鬥的 BGM，也可在劇情積木切換音樂。

🎧 音效庫

內建項目是瀏覽器即時合成音，不佔上傳空間；可試聽後在上方指定給操作。你上傳的音檔也會列在此處，並保存在專案素材庫。

⬇️ 下載後匯入編輯器

先在下方網站下載並解壓縮，將 MP3、OGG、WAV 或 M4A 檔拖進這裡，或按按鈕選檔；瀏覽器無法自行讀取你的下載資料夾。單檔上限 5 MB；較長 BGM 請先轉成較小的 OGG／MP3。大型音檔可能使瀏覽器本機儲存空間不足，請留意頁面警告並備份專案。

🧩 人物與物件

這裡與地圖、劇情編輯器使用同一份資料。修改後會立即同步到地圖與試玩。

🎨 遊戲整體風格

一鍵套用到開始畫面、對話框、選項、按鈕、地點提示與資料頁。套用後仍可逐項微調；上傳的圖片會保留。

👁 遊戲樣式預覽

預覽下方的對話框與按鈕。到「劇情互動」可逐句選頭像、立繪或不顯示圖片。

🕯 光源編輯器

一種光源可放在多張地圖上。每格 32×32 像素；光源圖片建議 32×32 或 64×64，上傳後最長邊會縮到 128。半徑以地圖格計算，燃燒時間只在試玩進行時計時；0 秒代表不會燃盡。

👁 照亮範圍預覽

預覽會顯示放置與手持的不同半徑。地圖的昏暗濃度與像素尺寸請到「地圖 → 光影與霧氣」設定。

🎞 動畫編輯器

把定格圖、自繪 CG、鏡頭、震動、轉場、人物登場、霧氣及音效依序排成一段動畫。可重複套用在開場或任一劇情事件；修改動畫後引用它的地方會同步更新。

🖱 CG 畫面與互動區編輯

選擇時間軸中的「自繪 CG 圖層」，即可在這裡拖曳圖片調位置。按「框選互動區」後，在圖片上拖出可點擊的範圍；區域文字與獎勵可在步驟設定中修改。

請先選擇一個 CG 步驟。

👁 整段預覽

定格圖建議依「開始畫面」設定的寬×高繪製；自繪 CG 可畫更大，最長邊可到 4096 像素。地圖人物仍以一格 32×32 像素定位。

新手教學：做出你的第一個遊戲

① 五分鐘快速上手
  1. 到「🗺 地圖」，選地形後在地圖上拖曳畫。地圖不夠大，用「地圖大小」調整。
  2. 選「⭐ 新增事件」，點地圖放上一個 NPC，再到「🎨 創作工作室 → 🎬 劇情互動」編排對話與選項。
  3. 用「🧑 主角起點」決定出發位置，按「▶ 試玩」測試。
  4. 到「🚀 發布」產生遊戲代碼，備份或分享給朋友。
② 上傳素材與圖層
  1. 到「🎨 創作工作室 → 🎨 素材庫」上傳圖片（單格建議 32×32；大型物件依佔格數 × 32 繪製）；上傳後會另存到共用素材庫。其他專案可在此按「加入此專案」使用，也能載入帳號裡的雲端素材。
  2. 回地圖，在「② 我上傳的素材」點選，再在地圖上點或拖曳擺放。
  3. 圖層：素材會放在「④ 圖層」中亮起來的那一層。例如地板放下層、家具放中層。按「＋新增圖層」可以自己加，也能改名、調整上下順序、刪除。
  4. 勾「蓋住角色」的圖層會畫在主角上方（樹冠、屋簷）。「顯示」可暫時隱藏某層，方便編輯。
  5. 橡皮擦只擦目前選中的圖層。素材有透明處卻不想露出綠色，地形請選「無（透明）」。
③ 碰撞（走得過、走不過）

用「🧱 畫碰撞」在地圖上塗抹，紅色格子走不過去。素材也可以在「🎨 素材」勾選「有碰撞」。碰撞跟畫面顏色無關。

④ 人物與動作（差分圖）
  1. 到「🎨 創作工作室 → 🧍 人物與動作」上傳人物圖，把「橫向幾格」「直向幾格」填成和你的圖一樣，圖上會出現格子與畫格編號。
  2. 按「＋新動作」，在「畫格選法」選：
    　• 固定順序：點哪幾格就播哪幾格（例如眨眼點 0、1、0）。
    　• 依方向：先選「下」「左」「右」「上」某一個方向，再點格子（例如往下走點 0、5、10）。
  3. 想讓它在行走時播放，就勾「移動時播放」；停下後會保留最後方向，可在四方向停格欄各自指定畫格。點錯了可按「↶ 刪最後一格」。
  4. 非走路動作可選「事件指令手動播放」、「待機時定期播放」或「每次開始對話時播放」。眨眼建議設待機每 3～5 秒；劇情中也可用「🏃 主角動作」指令播放驚訝等動作。
  5. 按「設為主角」後，到「▶ 試玩」確認效果。
⑤ 對話與劇情分支
  1. 先到「🎨 創作工作室 → 🧍 人物與動作」設定主角名稱、走路速度與對話頭像。頭像或立繪可在同頁下方上傳。
  2. 在「🎨 創作工作室 → 🎬 劇情互動」選地圖與事件，按「🗣 主角發言」加入主角台詞；「💬 對話」可切換為 NPC、主角或旁白。對話可逐句調整立繪大小和位置。
  3. 加入「❓ 讓玩家選擇」可設定跳轉標籤、顯示條件與選後效果；選項後也可以接一條主角發言指令，讓主角回應玩家的選擇。
  4. 上方可預覽玩家畫面，流程檢查會提示找不到的標籤。按「▶ 從這裡試玩」可直接從事件旁測試。
  5. 不知道怎麼開始時，在事件設定按「📋 套用「審問」範例」，照著改最快。
⑥ 圖片尺寸速查（一格 32×32）
  • 可繪製地形（地板、牆面）：畫正方形 32×32 或 64×64，上傳後每格顯示 32×32。
  • 獨立地圖物件：一格 32×32；兩格沙發可畫 64×32 或 128×64，三格高的樹可畫 32×96 或 64×192。上傳最長邊縮到 512；放置時可調佔格、像素位移。
  • 人物圖：每格 32×48 或 64×96；3 欄 4 列整張分別為 96×192 或 192×384；整張最長邊縮到 768。
  • 地圖背景圖：格數 × 32；例如 40×30 格為 1280×960；最長邊縮到 2048。
  • 角色頭像：96×96 或 192×192；半身立繪：320×480 或 640×960；最長邊縮到 600。對話指令可調顯示寬度與位置。
  • 未來若加入道具圖示：建議 32×32 或 64×64；敵人圖：建議 128×128 或 256×256；戰鬥特效逐格圖：建議每格 64×64。這三類目前尚未提供圖片上傳。
⑦ 解謎推理怎麼做
  1. 在「📦 資料庫」新增線索。
  2. 調查物件的事件用「🔎 獲得線索」，玩家可在「☰ 選單」的筆記本查看。
  3. 審問 NPC 時用「📜 讓玩家出示證物」，對的跳一條路、錯的跳另一條。
  4. 用變數記錄信任度、真相，再用「若變數符合條件就跳到標籤」決定結局。
⑧ 開始畫面、人物物件與玩家操作
  1. 在「🎞 開始畫面」上傳背景、編輯與新增按鈕，並設定互動、背包、地圖、讀取存檔、離開及移動快捷鍵。到「📦 資料庫」可為個別道具設定使用鍵；「🎛 玩家介面」可設計資料頁的排版、透明度、顯示內容及按鈕。開始畫面背景建議 640×448 或 1280×896。
  2. 在「🧩 人物與物件」集中管理 NPC、調查物件、地點對話、存檔點、出口與蠟燭。NPC 可設定自主走動、隨機話題、預設對話圖片；物件可設定發光或靠近才出現。
  3. 在「🗺 地圖」可設定像素化昏暗、漸暗、霧氣與燈光閃爍；勾選即時預覽後點地圖可移動預覽位置。也可上傳玩家導覽圖。導覽圖建議尺寸為地圖格數 × 32。劇情指令可設置放置或手持照明、畫面抖動、暫停、淡入淡出及慢速鏡頭。
  4. 試玩時用空白鍵互動與繼續對話；按 I 開啟背包、詳細資料、線索和對話紀錄，亦可查看地圖和目前位置。
