# 像素工坊 · RPG 製作器

## 這次完成

- **對話與主角**：人物頁可設定主角名稱、地圖角色圖與對話頭像／立繪；劇情頁可直接加入「主角發言」，一般對話也可選 NPC、主角或旁白。NPC 可在集中編輯頁設定預設立繪與可選的隨機話題。
- **遊戲開始畫面**：可上傳背景，修改／排序／新增按鈕；內建新遊戲、讀取存檔、離開及自訂訊息動作。瀏覽器不允許網頁可靠地關閉分頁，因此「離開」會返回開始畫面並提示玩家關閉分頁。
- **人物與物件編輯頁**：集中管理各地圖 NPC、調查物件、指定位置對話、存檔點、出口與蠟燭；可編輯外觀、座標、對話圖片、觸發條件、光點、靠近才顯示，以及 NPC 自主移動的間隔和半徑。出口預設連到下一張地圖；只有一張地圖時會建立下一張地圖。
- **人物動作圖**：同一人物的不同動作可以各自上傳圖片並指定欄列；雲端儲存會將這些動作圖片也上傳至 Storage。
- **試玩**：空白鍵互動與繼續對話、I 鍵開啟背包與詳細資料（兩鍵可在開始畫面設定）、半透明地點提示、導覽地圖與玩家位置、昏暗視野、放置或手持照明、存檔點、傳送轉場、畫面抖動／暫停／慢速移鏡。背包面板含道具、狀態、線索及對話紀錄。
- **流程編排**：劇情指令可拖曳標題調整順序，新增儲存、照明與畫面演出指令；條件仍使用原有的標籤和變數流程。
- 每個圖片上傳入口加入像素尺寸提示：地圖素材及其旋轉圖、地圖背景、人物行走圖、角色頭像與半身立繪；教學另列未來道具圖示、敵人圖、戰鬥特效圖的預定尺寸。地圖一格為 32×32。
- 對話指令新增立繪顯示寬度、水平位移、垂直位移，可在「劇情互動」即時預覽，試玩也會使用同樣設定。舊對話未設定時採用預設值。
- 人物非走路動作新增播放時機：事件指令手動播放、待機時定期播放、每次開始對話時播放。待機間隔可設定；眨眼可選 3～5 秒。一次只允許同一類自動時機對應一個動作，避免重疊。
- 新增獨立的「🎬 劇情互動」工作區：依地圖選事件、顯示指令流程、分組新增對話與互動、上下移動／複製／刪除指令，並能複製或新增整個事件。
- 選項編輯增加玩家文字、標籤跳轉、出現條件（開關、線索、變數門檻）及選後效果（變數加減、打開開關）。實際試玩會依條件隱藏選項並套用效果。
- 增加玩家畫面預覽與流程檢查；缺少跳轉標籤、重複標籤和空白選項會提示。可直接從目前事件附近試玩，且不會詢問載入舊存檔。
- 保留原本的地圖、人物、事件、音訊、資料庫及試玩流程。
- 地圖操作加入矩形鋪設、「重做」按鈕，以及 Ctrl/Cmd+Z、Ctrl/Cmd+Y、Ctrl/Cmd+Shift+Z 快捷鍵。
- 事件出現條件增加「變數至少達到某值」與「需要某線索」。
- Supabase 新增獨立的 `rpg_projects` 草稿表、`rpg_publications` 公開版本表及 `rpg-assets` 素材桶。草稿由登入者專屬權限保護；公開版本可由玩家讀取。
- 編輯器新增註冊／登入、雲端儲存、專案清單、另存新專案、載入、發布、下架、複製遊玩連結。圖片、立繪與音訊於儲存時從內嵌資料轉為 Storage 檔案網址。
- 玩家以 `?game=專案ID` 開啟已發布版本時，畫面只顯示遊戲，隱藏編輯工具。

## 如何使用

1. 用網頁伺服器開啟 `index.html`。直接雙擊本機檔案仍能編輯，但 `file://` 網址無法分享給玩家。
2. 到「🎞 開始畫面」設定背景、按鈕與快捷鍵；到「🧍 人物」指定主角圖與對話圖片。圖片上傳後可在「🎨 素材」分類中重新命名或刪除。
3. 到「🧩 人物與物件」新增或選取 NPC、調查點、存檔點與出口，再按「編輯對話與互動」。到「🎬 劇情互動」按類別加入指令，點開對話或選項修改文字；用「預覽」檢查外觀與流程提示。按「從這裡試玩」從事件旁開始測試。
   對話中可選上傳的立繪或頭像，再調整顯示寬度、水平及垂直位置。
   到「🧍 人物」新增動作後，點選畫格並設定「播放時機」；眨眼建議選「待機時定期播放」。
4. 在「🚀 發布」用電子郵件及密碼註冊／登入。若 Supabase 要求驗證信箱，先完成驗證。
5. 完成編輯後按「儲存雲端草稿」。首次儲存會建立專案並上傳素材。之後按「我的專案」可載入。
6. 按「發布目前版本」。發行版本會保留當下資料；後續草稿修改要再按一次發布，玩家才看得到。
7. 要建立另一個雲端專案，先按「另存為新專案」，再按「儲存雲端草稿」。

## 目前發布狀態

Supabase 後端已建立，原始碼已放在 GitHub 的獨立 `rpg-maker/` 資料夾分支，供審查。公開網站尚未上線，故目前無可分享的玩家網址。Site 發布流程在向來源同步工具傳送憑證時遭自動權限審查拒絕；GitHub 既有儲存庫的 Pages 也尚未啟用。雲端介面和後端資料結構已備妥，但登入後的完整儲存／發布流程尚無使用者帳號可做端對端驗證。

## Supabase 容量判斷

現有專案資料庫約 14 MB，Storage 在檢查時為 0 個檔案、0 bytes。Supabase Free 方案的資料庫配額是每專案 500 MB，Storage 是每組織 1 GB；目前沒有必要換新帳號。日後若大量上傳音訊或高解析度背景，應定期查看 Supabase 用量頁。此工具的素材桶為公開讀取，請勿上傳私密素材。

## 與 RPG Maker MZ 相比，下一步最重要的差距

1. **事件系統**：已有集中編輯、NPC 隨機走動及可拖曳指令；下一階段仍需事件頁、自我開關、共用事件、指定移動路線與真正可巢狀的積木條件分支。現在的標籤跳轉功能能做基本劇情，但大型遊戲容易難以維護。
2. **地圖編輯**：有地形、碰撞、素材圖層和填色，仍缺框選複製、自動拼接地形與區域標記。
3. **RPG 資料庫與戰鬥**：現在只有基本道具、敵人、HP 與簡易戰鬥；仍缺角色成長、隊伍、職業、裝備、技能、狀態、敵群及完整戰鬥畫面。
4. **發行品質**：仍缺版本歷史、多存檔欄位、大型素材管理、離線儲存擴容和獨立遊戲包匯出。
