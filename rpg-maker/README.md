## 如何使用

1. 用網頁伺服器開啟 `index.html`。直接雙擊本機檔案仍能編輯，但 `file://` 網址無法分享給玩家。
2. 在「🚀 發布」用電子郵件及密碼註冊／登入。若 Supabase 要求驗證信箱，先完成驗證。
3. 完成編輯後按「儲存雲端草稿」。首次儲存會建立專案並上傳素材。之後按「我的專案」可載入。
4. 按「發布目前版本」。發行版本會保留當下資料；後續草稿修改要再按一次發布，玩家才看得到。
5. 要建立另一個雲端專案，先按「另存為新專案」，再按「儲存雲端草稿」。

## 目前發布狀態

Supabase 後端已建立，原始碼已放在 GitHub 的獨立 `rpg-maker/` 資料夾分支，供審查。公開網站尚未上線，故目前無可分享的玩家網址。Site 發布流程在向來源同步工具傳送憑證時遭自動權限審查拒絕；GitHub 既有儲存庫的 Pages 也尚未啟用。雲端介面和後端資料結構已備妥，但登入後的完整儲存／發布流程尚無使用者帳號可做端對端驗證。

## Supabase 容量判斷

現有專案資料庫約 14 MB，Storage 在檢查時為 0 個檔案、0 bytes。Supabase Free 方案的資料庫配額是每專案 500 MB，Storage 是每組織 1 GB；目前沒有必要換新帳號。日後若大量上傳音訊或高解析度背景，應定期查看 Supabase 用量頁。此工具的素材桶為公開讀取，請勿上傳私密素材。

## 與 RPG Maker MZ 相比，下一步最重要的差距

1. **事件系統**：仍缺事件頁、自我開關、共用事件、NPC 移動路線與巢狀條件分支。現在的標籤跳轉功能能做基本劇情，但大型遊戲容易難以維護。
2. **地圖編輯**：有地形、碰撞、素材圖層和填色，仍缺框選複製、矩形筆刷、自動拼接地形與區域標記。
3. **RPG 資料庫與戰鬥**：現在只有基本道具、敵人、HP 與簡易戰鬥；仍缺角色成長、隊伍、職業、裝備、技能、狀態、敵群及完整戰鬥畫面。
4. **發行品質**：仍缺版本歷史、多存檔欄位、大型素材管理、離線儲存擴容和獨立遊戲包匯出。
