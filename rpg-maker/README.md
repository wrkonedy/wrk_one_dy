# 像素工坊 · RPG 製作器

## 這次完成

- **從新增地圖直接試玩**：地圖頁新增「▶ 從此地圖試玩」。即使這張地圖沒有設定主角起點，也會尋找可站立的格子進入試玩；若沒有可站立格子，會提示先調整地形或碰撞。
- **存檔點與讀檔**：背包選單與原存檔快捷鍵改為「讀取存檔」。遊戲進度只能透過「存檔點」事件儲存；普通事件誤放儲存指令會提示修改類型。既有含儲存指令的事件會轉為存檔點類型。
- **圖片背包與物品檢閱**：資料庫中的道具可上傳 32×32／64×64 小圖與 320×448／640×896 檢閱大圖，撰寫介紹，設為只供檢閱。背包可用方向鍵、滑鼠滾輪上下選擇，旁邊會顯示物品介紹和大圖，並可放大檢閱。
- **音效編輯器**：可逐項設定按鈕、選單移動、確認、關閉、腳步、調查、取得物品、使用道具、存讀檔、轉場、戰鬥等音效與音量。提供 15 個原創即時合成音效，或使用上傳音檔；可試聽、全域靜音。

- **多格物件與位置微調**：素材庫可設定物件預設寬高（每格 32×32 像素）。地圖上選取單件物件後，可覆寫佔格數、輸入水平／垂直像素位移、按 1 像素方向鍵微調，或拖曳到其他格。大型素材保持原圖比例並依設定大小顯示；碰撞會依跨格範圍計算。調查物件也可選擇素材圖、設定獨立佔格與像素位置，互動與阻擋範圍隨之更新。

- **可重用的動畫編輯器**：以時間軸組合定格圖、字幕、平移縮放、震動、淡入淡出、人物登場、霧氣變化、地圖切換與聲音。可預覽、略過，指定為新遊戲開場動畫，或從劇情事件播放；動畫與圖片隨專案儲存及發布。
- **光源編輯器**：蠟燭、提燈、火柴可分別設定放置／手持半徑、燃燒秒數、點火道具與拾取、手持、放置規則。試玩存檔保留剩餘燃料與光源位置。
- **像素化光影與霧氣**：每張地圖可調光影像素尺寸、暗處濃度、光線邊緣的漸層範圍、暗處顏色、進入地圖時漸暗時間、燈光閃爍，以及霧氣的濃度與移動速度。霧氣也可單獨用在非昏暗地圖。
- **地圖即時預覽**：勾選「在編輯地圖即時預覽」後，調整光影設定會立即反映在地圖上；點地圖可移動預覽位置，並可勾選「預覽手持蠟燭」。取消預覽即可繼續畫地圖。
- **跨專案共用素材**：上傳過的圖片、人物動作、音效與字體會另存到此裝置的共用素材庫。新專案可按「加入此專案」重用；刪除目前專案內的素材不會刪除共用庫版本。登入後還可從同帳號已儲存的雲端專案載入素材，帶入另一個專案或裝置。
- **記住帳號**：雲端登入頁新增「在此裝置記住登入」。勾選後保存可更新的登入憑證，重新開啟編輯器時自動恢復；不保存密碼。可取消勾選或按登出清除本機記住的憑證。
- **多專案製作**：頂端「📁 專案」可建立、開啟、複製、改名、刪除不同遊戲。本機資料、素材與試玩存檔依專案分開；原有作品會保留並列為第一個專案。每個本機專案可個別連結雲端草稿，從雲端載入的作品也會成為可切換的本機專案。
- **自由縮放地圖編輯**：地圖頁提供 25%～600% 滑桿、放大／縮小與符合寬度。放大後一格可以顯示到 192×192 畫面像素，方便編輯小房間和細部配置；實際遊戲格子仍以 32×32 像素為準。縮放比例會隨專案保存。
- **Shift 奔跑與環境速度**：試玩時按住 Shift 奔跑，主角頁可設定奔跑速度；每張地圖可設定環境移動倍率，以及無照明時的昏暗減速。手持或放置照明生效時解除昏暗減速。劇情新增「改變主角移動狀態」指令，可設定受傷、遲緩等倍率與持續秒數，設為 1 可恢復正常。各倍率會一起計算。
- **雙角色互動動畫**：劇情「演出」新增指令，可指定主角、目前事件或同地圖另一個人物作為兩位參與者，分別選擇已上傳的人物動作、是否互相面對及演出時間。試玩時兩個動作會同時播放，演出後恢復原動作。
- **條件積木**：目前版加入「如果／否則／結束如果」的堆疊式條件區，可用變數、開關、線索、道具或金錢判斷；也有輸入密碼／答案指令。
- **創作工作室**：人物與動作、素材庫、人物與物件、劇情互動、對話與風格集中在同一個入口。人物圖、頭像、立繪及事件資料仍共用同一專案，修改後同步到預覽與試玩。
- **走路速度**：主角可調每格 70～600 毫秒；自主活動的 NPC 可個別設定走路速度，並與移動間隔分開控制。
- **對話框編輯**：可調上／中／下位置、水平與垂直邊距、透明度、框內頭像大小、逐字速度及逐字音效。可上傳自繪對話框圖片，並即時預覽。
- **頭像與立繪**：每句台詞可選「依整體設定／框內頭像／框外立繪／不顯示圖片」，也能覆蓋該人物的預設圖片。框內頭像與名字、文字同處一個對話框；頭像可單獨上傳、重新命名及從素材庫刪除。
- **一鍵統一風格**：提供深色像素、森林像素、羊皮紙像素、柔和現代四組預設，將遊戲內對話、選項、按鈕與面板一併套用。可再調顏色、像素邊框、字體，或上傳自繪對話框、按鈕、面板圖片與字體檔。
- **事件試玩操作**：從事件旁試玩時，主角會自動面向該事件。可用空白鍵或畫面上的「互動／繼續」按鈕交談與翻頁；未設定觸發方式的舊事件也會照預設互動方式執行。
- **方向停格**：主角與自主走動的 NPC 停下時會保留最後的上下左右面向；人物的走路動作可逐方向指定站立畫格。主角方向也會寫入存檔。
- **人物與物件集中編輯**：同一頁加入圖片與位置預覽、直接上傳人物圖和對話圖片、編輯出現條件、第一句對話、追加 NPC／主角台詞、複製及搬移地圖。這些設定使用地圖與劇情編輯器的同一事件資料，修改後會同步顯示。
- **快捷鍵**：互動、背包、地圖、讀取存檔、離開與四方向移動都能各自設定；道具在資料庫可指定專用使用鍵，重複按鍵會提示衝突。方向鍵仍可作為移動備用鍵。
- **玩家資料頁**：新增「🎛 玩家介面」，可調標題、排列方式、背景色、強調色、透明度、分頁及按鈕顯示、名稱和順序，以及詳細資料顯示欄位；有即時預覽。
- **預設符號**：主角、事件／NPC／物件及地形的預設 emoji 都可以清除或修改；清除事件符號後事件仍可在編輯器中選取。
- **對話與主角**：人物頁可設定主角名稱、地圖角色圖與對話頭像／立繪；劇情頁可直接加入「主角發言」，一般對話也可選 NPC、主角或旁白。NPC 可在集中編輯頁設定預設立繪與可選的隨機話題。
- **遊戲開始畫面**：可上傳背景，修改／排序／新增按鈕；內建新遊戲、讀取存檔、離開及自訂訊息動作。瀏覽器不允許網頁可靠地關閉分頁，因此「離開」會返回開始畫面並提示玩家關閉分頁。
- **人物與物件編輯頁**：集中管理各地圖 NPC、調查物件、指定位置對話、存檔點、出口與蠟燭；可編輯外觀、座標、對話圖片、觸發條件、光點、靠近才顯示，以及 NPC 自主移動的間隔和半徑。出口預設連到下一張地圖；只有一張地圖時會建立下一張地圖。
- **人物動作圖**：同一人物的不同動作可以各自上傳圖片並指定欄列；NPC 可選擇地圖上顯示的動作，待機與對話動作會依設定播放。雲端儲存會將這些動作圖片也上傳至 Storage。
- **試玩**：空白鍵互動與繼續對話、I 鍵開啟背包與詳細資料（快捷鍵可在開始畫面設定）、半透明地點提示、導覽地圖與玩家位置、昏暗視野、放置或手持照明、存檔點、傳送轉場、畫面抖動／暫停／慢速移鏡。背包面板含道具、狀態、線索及對話紀錄。
- **流程編排**：劇情指令可拖曳標題調整順序，新增儲存、照明與畫面演出指令；條件仍使用原有的標籤和變數流程。
- 每個圖片上傳入口加入像素尺寸提示：地圖素材及其旋轉圖、地圖背景、人物行走圖、角色頭像與半身立繪；教學另列未來道具圖示、敵人圖、戰鬥特效圖的預定尺寸。地圖一格為 32×32。
- 對話指令新增立繪顯示寬度、水平位移、垂直位移，可在「劇情互動」即時預覽，試玩也會使用同樣設定。舊對話未設定時採用預設值。
- 人物非走路動作新增播放時機：事件指令手動播放、待機時定期播放、每次開始對話時播放。待機間隔可設定；眨眼可選 3～5 秒。一次只允許同一類自動時機對應一個動作，避免重疊。
- 新增獨立的「🎬 劇情互動」工作區：依地圖選事件、顯示指令流程、分組新增對話與互動、上下移動／複製／刪除指令，並能複製或新增整個事件。
- 選項編輯增加玩家文字、標籤跳轉、出現條件（開關、線索、變數門檻）及選後效果（變數加減、打開開關）。實際試玩會依條件隱藏選項並套用效果。
- 增加玩家畫面預覽與流程檢查；缺少跳轉標籤、重複標籤和空白選項會提示。可直接從目前事件附近試玩，且不會詢問載入舊存檔。
- 保留原本的地圖、人物、事件、音訊、資料庫及試玩流程。
- 地圖操作加入矩形鋪設、「重做」按鈕，以及 Ctrl/Cmd+Z、Ctrl/Cmd+Y、Ctrl/Cmd+Shift+Z 快捷鍵。
- 事件出現條件增加「變數至少達到某值」與「需要某線索」。
- Supabase 新增獨立的 `rpg_projects` 草稿表、`rpg_publications` 公開版本表及 `rpg-assets` 素材桶。草稿由登入者專屬權限保護；公開版本可由玩家讀取。
- 編輯器新增註冊／登入、雲端儲存、專案清單、另存新專案、載入、發布、下架、複製遊玩連結。圖片、立繪與音訊於儲存時從內嵌資料轉為 Storage 檔案網址。
- 玩家以 `?game=專案ID` 開啟已發布版本時，畫面只顯示遊戲，隱藏編輯工具。

## 如何使用

所有編輯頁面現在使用與「劇情互動」相同的寬版工作區；窄螢幕會依視窗寬度縮排。公開遊玩的遊戲畫面依專案設定的畫框尺寸顯示。

在「🎞 開始畫面 → 共用遊戲畫面尺寸」可為每個專案設定寬、高，或選 640×448、800×600、960×672、1280×720 預設。開始選單、商標片頭、前言、動畫預覽與地圖遊玩會使用同一畫框並置中；視窗較窄時會等比縮小。地圖仍以 640×448 像素繪製，選擇其他長寬比例時會留黑邊以免人物與格子變形。自繪背景與前言圖片建議依所選畫框尺寸繪製，或畫成兩倍大小以保持清晰。

1. 用網頁伺服器開啟 `index.html`。直接雙擊本機檔案仍能編輯，但 `file://` 網址無法分享給玩家。先到「📁 專案」建立或開啟想製作的故事。
2. 到「🎞 開始畫面」設定背景、按鈕與各功能快捷鍵；到「🎛 玩家介面」設計資料頁。進入「🎨 創作工作室 → 🧍 人物與動作」指定主角圖、各方向停格、走路速度、頭像與立繪。圖片上傳後可在「🎨 素材庫」重新命名或刪除。
3. 到「🎨 創作工作室 → 🧩 人物與物件」新增或選取 NPC、調查點、存檔點與出口；可在同頁直接修改圖片、條件、NPC 移動速度及第一句台詞，再按「完整對話與互動流程」。到「🎬 劇情互動」按類別加入指令，點開對話或選項修改文字；每句可指定框內頭像、框外立繪或無圖。用「預覽」檢查外觀與流程提示，按「從這裡試玩」從事件旁開始測試。
   到「🧍 人物與動作」新增動作後，點選畫格並設定「播放時機」；眨眼建議選「待機時定期播放」。
4. 到「🎨 創作工作室 → 🖼 對話與風格」先按一組風格預設，再調整對話框、文字速度與音效。自繪的 UI 圖片與字體可直接上傳，也會收入素材庫。試玩時檢查對話框、選項、按鈕是否符合預期。
5. 在「🚀 發布」用電子郵件及密碼註冊／登入。若 Supabase 要求驗證信箱，先完成驗證。
6. 完成編輯後按「儲存雲端草稿」。首次儲存會建立專案並上傳素材。之後按「我的專案」可載入。
7. 按「發布目前版本」。發行版本會保留當下資料；後續草稿修改要再按一次發布，玩家才看得到。
8. 要建立另一個雲端專案，先按「另存為新專案」，再按「儲存雲端草稿」。

做沙發、樹或桌上小物時，先到「🎨 素材庫」上傳圖片並設定預設佔格，再到「🗺 地圖」放置。切換「👆 選取」點圖片，即可調整單件寬高和 ±1 像素位置。可調查的物件則在「🧩 人物與物件」選物件圖片、佔格與微調值。兩格沙發建議 64×32 或 128×64；三格高的樹建議 32×96 或 64×192。

光影設定在「🗺 地圖」上方的「🌙 光影與霧氣」。先勾選即時預覽，再調整滑桿；像素尺寸建議從 8 px 開始。素材可在「🎨 創作工作室 → 🎨 素材庫」下方的共用庫帶入目前專案。若要在另一台裝置使用，先儲存雲端草稿，再於另一台裝置登入並按「載入帳號的雲端素材」。

製作雙角色動畫時，先在「人物與動作」為兩位角色上傳並設定動作，再到人物事件的「劇情互動 → 演出」加入「雙角色互動動畫」。要做昏暗房間，在地圖頁勾選昏暗地圖並調整兩個移動倍率；到主角頁設定 Shift 奔跑速度。

## 蠟燭、提燈與火柴

1. 到「🎨 創作工作室 → 🕯 光源編輯器」選一種光源，分別調整放置和手持半徑、燃燒秒數、可否手持／放置／拾起。0 秒表示不會燃盡。右側可立即切換兩種範圍預覽。
2. 「需要的道具」可留空，玩家就能直接點亮；若選火柴，再勾「點亮時消耗 1 個所需道具」，每次點火會用掉一根。也可以取消消耗，做成可重複使用的點火工具。火柴本身可作為約 12 秒的手持光源；所有預設數值都能修改。
3. 到「人物與物件」新增「蠟燭／燈」，選擇光源種類與進入遊戲時是否點亮。試玩時走到光源前，按互動鍵可點亮、熄滅或拾起。玩家背包可手持、收回或放置在面前的空格；放下後仍可互動拾起。
4. 燃燒時間以試玩中的時間計算，存檔會保留剩餘秒數、手持與放置狀態；關閉遊戲後計時暫停。點亮後熄滅不會補滿燃料。若勾選「燃盡後重新點亮會補滿燃料」，光源可再次使用。

上傳光源地圖圖案建議 32×32 或 64×64 像素，畫面中顯示為一格 32×32；圖片會進素材庫並隨專案雲端草稿一同上傳。舊版「照明／蠟燭」事件指令仍可繼續運作；新的蠟燭物件使用光源編輯器設定。

## 製作開場與劇情動畫

1. 到「🎨 創作工作室 → 🎞 動畫編輯器」按「＋新動畫」，取名後由下方加入演出步驟。時間軸由上往下播放，每步可調秒數、上移、下移、複製或刪除；也能加入開場與人物登場範例。
2. 可加入定格圖片與字幕、定格圖緩慢平移／縮放、淡入或淡出、地圖鏡頭移動、畫面震動、人物登場或移動、霧氣散去／聚攏、切換地圖、音效／背景音樂及等待。按「▶ 播放預覽」檢查整段，按「■ 停止」結束。編輯區預覽以簡化的地圖背景及人物符號示意；實際地圖演出請在試玩檢查。
3. 到「🎞 開始畫面」分別指定「啟動片頭」與「新遊戲前言與操作說明」。播放順序是 **作者／商標片頭 → 開始選單 → 按新遊戲後的前言 → 地圖**。讀取存檔不會重播新遊戲前言；返回選單也不會重播商標片頭。可按「＋建立商標片頭」或「＋建立前言範例」產生獨立的時間軸，再上傳自己的商標、警示圖、前言或操作圖卡。到「🎬 劇情互動 → 演出」加入「播放動畫」指令，也能在任意事件中使用動畫。
4. 人物登場可選主角、同地圖事件或「觸發動畫的事件」，填起點與終點格數；起點可為 -1，製作從地圖外走入。可選該人物已設定的動作。演出後位置會保留；霧氣變化也會保留於該地圖，並隨遊戲存檔。玩家可用動畫畫面右上角的「略過動畫」跳過。
5. 要放入自繪 CG，加入「🎨 自繪 CG 圖層／互動」，選素材庫圖片或直接上傳。可調整中心位置、寬度、不透明度、移動距離與結束倍率，並選擇淡入、滑入、放大或震動等進場效果。可疊多張透明圖；取消「取代前一張 CG」會保留前一圖層。加入「移除 CG 圖層」可淡出所有圖層。
6. 在 CG 步驟按「在下方畫面編輯位置與範圍」。直接拖曳圖片可移位置；按「框選互動區」後在圖片上拖出範圍。回到該步驟可修改範圍、名稱、調查文字及點擊效果。點擊可顯示文字、取得線索或道具、開啟劇情開關。勾選「等待玩家完成調查」時，玩家可在 CG 畫面點擊任意調查區，再按「完成調查」繼續；也可略過整段動畫。「每局遊戲只領取一次」的結果會跟隨遊戲存檔。
7. 要交代場景而不讓主角或 NPC 出現，勾選動畫上方的「純場景演出」。底圖選「目前地圖」會保留地圖風景但隱藏人物與事件；選「純黑底圖」適合商標、警示與全畫面自繪圖卡。預覽與遊戲播放都使用此設定。每張定格圖可選「完整顯示」、置中字幕與「顯示完後等待玩家按繼續」，方便做連續的前言頁。要安排人物登場，請在該動畫取消純場景演出。

定格圖建議依「開始畫面」設定的寬×高繪製，預設為 640×448；透明 PNG 也可用，上傳後最長邊縮到 2048。自繪 CG 可畫成畫框的 2 倍，最長邊可到 4096；未超過時保留原檔，較大時才縮圖，並維持長寬比例。原畫模式會平滑顯示，像素風模式可保留硬邊；放大超過原圖尺寸仍可能失真。圖片會進素材庫，可在不同動畫中重用，按「儲存雲端草稿」時會與專案一起上傳。這是以定格圖、CG 圖層、地圖角色與效果組合的劇情時間軸；目前沒有逐格繪圖、骨架動畫或影片檔編輯。

高解析度 CG 檔案可能超過瀏覽器的本機專案儲存容量；若頁面上方出現空間不足警示，請立即儲存雲端草稿或匯出遊戲代碼備份。雲端素材上傳後，本機專案會改用素材網址，通常能釋出本機空間。

## 目前發布狀態

Supabase 後端已建立，原始碼已放在 GitHub 的獨立 `rpg-maker/` 資料夾分支，供審查。公開網站尚未上線，故目前無可分享的玩家網址。Site 發布流程在向來源同步工具傳送憑證時遭自動權限審查拒絕；GitHub 既有儲存庫的 Pages 也尚未啟用。雲端介面和後端資料結構已備妥，但登入後的完整儲存／發布流程尚無使用者帳號可做端對端驗證。

## Supabase 容量判斷

現有專案資料庫約 14 MB，Storage 在檢查時為 0 個檔案、0 bytes。Supabase Free 方案的資料庫配額是每專案 500 MB，Storage 是每組織 1 GB；目前沒有必要換新帳號。日後若大量上傳音訊或高解析度背景，應定期查看 Supabase 用量頁。此工具的素材桶為公開讀取，請勿上傳私密素材。

## 與 RPG Maker MZ 相比，下一步最重要的差距

1. **事件系統**：已有集中編輯、NPC 隨機走動及可拖曳指令；下一階段仍需事件頁、自我開關、共用事件、指定移動路線與真正可巢狀的積木條件分支。現在的標籤跳轉功能能做基本劇情，但大型遊戲容易難以維護。
2. **地圖編輯**：有地形、碰撞、素材圖層和填色，仍缺框選複製、自動拼接地形與區域標記。
3. **RPG 資料庫與戰鬥**：現在只有基本道具、敵人、HP 與簡易戰鬥；仍缺角色成長、隊伍、職業、裝備、技能、狀態、敵群及完整戰鬥畫面。
4. **發行品質**：仍缺版本歷史、多存檔欄位、大型素材管理、離線儲存擴容和獨立遊戲包匯出。
